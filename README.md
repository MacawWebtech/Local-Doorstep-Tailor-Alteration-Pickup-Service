# StitchDoor

Complete 16-page tailoring website. Extract the ZIP and open index.html using your usual local web server. Read documentation/USER-GUIDE.md for image replacement, page structure, interaction behavior and integration limits.

Palette: #000000, #7F011F, #F5EBD0. All image files are JPG. Booking/account/payment interfaces run locally and do not claim confirmed bookings, secure authentication or real payments.
